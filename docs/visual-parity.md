# Проверка переноса интерфейса

Оригинал — `../frontend/src`, используется только для чтения. Новый интерфейс — React/TypeScript и CSS Modules в `src/apps` и `src/components/ui`. Перенесены исходные значения тем, размеры, отступы, анимации меню, адаптивные правила, тексты и SVG-контуры иконок. Для Next.js используются App Router, client-компоненты для интерактивных экранов, локальные состояния и route handlers.

Для визуальной сверки исходные компоненты отдельно собраны во временной папке с React 16 и styled-components 5. Gatsby-навигация, Redux и сетевые hooks заменены локальными заглушками; сами исходные компоненты и стили не изменялись. Это проверка отображения компонентов, а не запуск старого backend. Снимки сняты в одном Chromium с одинаковым viewport, без случайной заливки стран и журнала, с отключёнными анимациями.

Также сравнивались окно выбора бедствия, двухуровневая шапка отчётов и футер. Браузерные тесты проверяют обе темы, язык, позицию меню, шесть сценариев, воспроизведение, перезагрузку отчёта, CSV и все страницы локальной PDF-инструкции на двух языках. Скриншоты тестов сохраняются в `test-results/`.

Согласованные отличия: удалены авторство и внешние иллюстрации; историческая отметка находится в «О приложении». В PDF удалено поле Author, содержание страниц сохранено. Исправлены пропуск последней страницы PDF, обработка нажатий при смене SVG, сохранение настроек при перезагрузке и отправка запросов в текущий Next.js API. Без токена Mapbox показывается локальная карта и сообщение; живые тайлы требуют нового токена. Юридическая атрибуция Mapbox сохранена.
