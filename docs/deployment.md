# Vercel, Neon и Mapbox

Репозиторий подготовлен к деплою, но удалённые проекты и базы не созданы. Публикация не выполнялась. Реальное подключение Neon и Mapbox необходимо проверить после добавления собственных переменных окружения.

## Переменные

| Переменная                 | Где доступна                     | Назначение                                                                 |
| -------------------------- | -------------------------------- | -------------------------------------------------------------------------- |
| `NEXT_PUBLIC_MAPBOX_TOKEN` | Браузер, встраивается при сборке | Новый публичный токен Mapbox с разрешёнными URL приложения                 |
| `DATABASE_URL`             | Только сервер                    | Строка подключения Neon PostgreSQL; обязательна для постоянной истории     |
| `SESSION_SECRET`           | Только сервер                    | Случайная строка не менее 32 символов для подписи cookie; обязательна с БД |

Секреты не коммитить. `.env.local` исключён из Git. Не используйте префикс `NEXT_PUBLIC_` для подключения БД или секрета сессии. Mapbox требует именно публичный токен `pk.*`, а не секретный `sk.*`.

Секрет можно сгенерировать в devenv:

```sh
devenv shell -- node -e 'console.log(require("node:crypto").randomBytes(32).toString("hex"))'
```

## Neon

1. Создать проект Neon и базу PostgreSQL в регионе рядом с Vercel Functions. Для preview предпочтительна отдельная ветка Neon.
2. Скопировать connection string из Neon в `DATABASE_URL` файла `.env.local`. Драйвер `@neondatabase/serverless` выполняет запросы через HTTP; отдельный пул Node.js не нужен.
3. Задать `SESSION_SECRET`.
4. Выполнить `devenv shell -- ea-db-migrate`. Скрипт читает `.env.local`, создаёт `ea_reports` и индекс в транзакции. Повторный запуск безопасен. Существующие старые таблицы не удаляются.

Не загружайте старый `DB.sql` в Neon целиком: в нём расширение `adminpack`, старые последовательности и тестовые записи. Справочники уже включены в приложение и не требуют отдельного импорта.

## Vercel

1. Опубликовать **новый** репозиторий `emergency-analyzer` в выбранном Git-хостинге и импортировать его в Vercel.
2. Framework preset: Next.js. Root Directory: корень нового репозитория. Если импортируете родительскую папку с обоими архивами, root должен быть `emergency-analyzer`.
3. Node.js: 24.x. Install/build указаны в `vercel.json`: `pnpm install --frozen-lockfile`, `pnpm build`.
4. Добавить три переменные для нужного окружения Production/Preview. `NEXT_PUBLIC_MAPBOX_TOKEN` должен существовать **во время сборки**; после смены токена нужен redeploy.
5. Убедиться, что миграция выполнена для соответствующей Neon-ветки, затем деплоить.

Миграция намеренно не запускается на каждой сборке: preview не должен менять production-схему. Отдельные API_ADDRESS/PROXY_URL и CORS-прокси больше не нужны — UI и API используют один origin.

## Проверка после подключения

- `GET /api/health` возвращает `status: ok`. Это проверка приложения, не проверка доступности БД.
- Создать сценарий: `POST /api/simulations` возвращает 201 и `persistent: true`.
- Открыть отчёты, перезагрузить страницу и снова открыть расчёт. Удалить тестовый отчёт.
- В другом профиле браузера список должен быть пустым, а чужой ID — возвращать 404.
- Убедиться, что Mapbox загрузился, зоны появляются и движутся, навигация и обязательная атрибуция карты видимы.
- При отключённом токене остаётся обзорная карта и явно показано отсутствие детализации.

Отчёты привязаны к подписанной HttpOnly cookie со сроком один год. Это изоляция анонимных браузерных сессий, не система пользовательских аккаунтов. Очистка cookie или смена `SESSION_SECRET` теряет доступ к прежним отчётам. Данные автоматически не удаляются по истечении cookie; для длительной эксплуатации следует определить политику хранения. В UI показываются последние 200 отчётов сессии.

Без `DATABASE_URL` приложение остаётся рабочим, но отчёты доступны только в текущей вкладке. Если БД настроена, но недоступна, API отвечает 503, а не выдаёт временное сохранение за постоянное.

Официальные инструкции: [Next.js на Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs), [драйвер Neon](https://neon.com/docs/serverless/serverless-driver), [Mapbox GL JS](https://docs.mapbox.com/mapbox-gl-js/guides/get-started/).
