# Источники данных

Все справочные данные перенесены из предоставленного локального архива. Новые внешние поставщики данных не подключены. Точный год и первичный источник каждой записи в старых файлах не указан; `legacy-2020` — метка набора эпохи исходного проекта, не подтверждение даты каждого значения.

| Источник                                                                                | Использование                                                     | Решение                                                                 |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `../backend/DB.sql`                                                                     | 190 стран, 597 регионов, параметры сценариев, 55 шаблонов событий | Локальный `historical.json` и `events.json`; явная историческая отметка |
| Java `Damage.java`                                                                      | Формулы, коэффициенты, химические таблицы                         | TypeScript-модули с описанными исправлениями                            |
| Локальный `frontend/src/components/world-map/countries.js`                              | Геометрия обзорной карты                                          | Статический JSON, сетевые запросы не требуются                          |
| Mapbox styles/tiles                                                                     | Детальная карта симуляции                                         | Сохранён, нужен новый публичный токен; атрибуция провайдера остаётся    |
| `imageup.ru`, `obotravlenii.ru`, `avatars.mds.yandex.net` и другие URL из колонок `url` | Иллюстрации                                                       | URL и изображения не перенесены                                         |
| GitLab raw через старый Express-прокси                                                  | PDF-справка, уведомления                                          | Локальные исходные PDF и тексты уведомлений, без сетевого прокси        |
| Старые личные профили, фотографии и блок об авторах                                     | Авторство                                                         | Удалены из нового приложения                                            |

SHA-256 исходных файлов находится в `source-manifest.json`. Справочники включены в сборку, их обновление — отдельное контролируемое изменение репозитория. Приложение не обращается к старому Java-серверу, Express-прокси или хостингам изображений.

Исходные демографические данные имеют заметные несоответствия (например, плотности населения некоторых стран), но не исправлялись догадками. Расчёты продолжают использовать эти исторические значения. Названия и принадлежность регионов также сохранены из архива.

Исторические глобальные константы: население 7 830 458 560, средняя плотность за пределами выбранной территории 30 чел./км². Они выделены в `src/core/simulation/damage.ts`. Обновление требует согласованного источника и новой версии набора данных.

Демонстрационный журнал использует исходные шаблоны, не является реальной новостной лентой и обновляется автоматически каждые пять секунд, как в исходнике. Сохранённые в старом SQL и Express JSON пробные симуляции не подмешиваются в историю новых посетителей.

PDF-инструкции взяты из локального `backend/src/main/resources/howto_{ru,en}.pdf`. Из копий удалено поле Author; остальные байты сохранены, включая страницы со скриншотами исторического интерфейса. Встроенные в PDF изображения не обращаются к внешним сервисам. PDF.js worker, шрифты и вспомогательные файлы копируются локально при `pnpm install`, CDN не используется.
