# Перенос и границы совместимости

## Функциональность

| Раньше                                       | Сейчас                                                                                                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Gatsby pages и Redux                         | Next.js App Router, TypeScript, CSS Modules, типизированные состояния                                           |
| `/`, случайная карта и журнал                | Исходная Mercator-карта, центральное меню и автоматический демонстрационный журнал                              |
| `/settings`                                  | Исходный последовательный выбор через модальные списки, поиск/сортировка, описания, симптомы и диапазоны вируса |
| `/start`                                     | Исходная карта с верхними play/finish/pause/reset и тремя строками результатов                                  |
| `/reports`                                   | Исходная двухуровневая таблица, повторный запуск и CSV                                                          |
| `/references`, внешние PDF                   | Те же локальные RU/EN-документы без имени автора в метаданных; показ всех семи страниц                          |
| Язык и тема                                  | Исходная нижняя панель; RU/EN и две темы, сохранение предпочтений                                               |
| Ссылка с произвольными полями ущерба         | ID серверного отчёта, проверка владельца                                                                        |
| Java Spring + PostgreSQL                     | Чистое TypeScript-ядро, Next.js Route Handlers, опциональный Neon                                               |
| Express fallback с фиксированным damage.json | Реальный расчёт без фиктивных успешных ответов                                                                  |

Внешний вид взят из `frontend/src`: значения тем, геометрия карты, размеры, отступы, адаптивные правила, тексты, SVG-контуры иконок версии 3.11.0. Общие примитивы вынесены в `components/ui`, стили отдельных экранов — в CSS Modules. Настройки сохраняются в текущей вкладке и после перезагрузки. Изменения относительно отображения исходника ограничены удалением авторства и внешних иллюстраций, согласованной исторической отметкой в «О приложении», сообщениями ошибок и недоступного Mapbox. Атрибуция Mapbox сохранена.

Дополнительные поля сооружений и химических коэффициентов поддерживаются ядром/API, но не добавлены в исходный интерфейс. Химический сценарий использует значения по умолчанию из `core/simulation/schema.ts`. Новые карточки, боковая навигация, фильтры отчётов и другие элементы предыдущего варианта переноса удалены.

API сознательно обновлён, это не drop-in сервер для старого Gatsby. Справочники доступны только для чтения: публичные CRUD старых Spring-контроллеров не публикуются как административный API. Для изменения справочников нужно менять версионируемые JSON в репозитории. История расчётов неизменяема: повторный расчёт создаёт новый отчёт вместо PUT старого результата.

## HTTP API

- `GET /api/health` — доступность приложения и версии модели/данных.
- `GET /api/catalog/:name` — `{ items, dataVersion, historical }`; для regions есть `?countryId=`.
- `POST /api/simulations` — тело по `inputSchema`, ответ `{ report, persistent }`.
- `GET /api/simulations` — последние 200 отчётов текущей подписанной сессии.
- `GET /api/simulations/:id`, `DELETE /api/simulations/:id` — доступ только владельцу сессии.

Вход проверяется Zod, размер JSON ограничен 32 KiB. Неизвестные ID, чужой регион, неверный набор симптомов и выход за диапазоны отклоняются. SQL параметризован. Записи не используют память или файловую систему Vercel. Cookie HttpOnly/SameSite и проверка Origin защищают браузерные запросы от подмены сессии и межсайтовых изменений; аккаунты и распределённый rate limiting не входят в эту миграцию.

## Численная модель `legacy-corrected-v2`

Это **не побитовая копия** всех Java-результатов и не новая научная модель. Сохранены основные формулы радиусов и таблицы коэффициентов, но воспроизведение дефектов исходника не является целью. Изменения перечислены явно:

1. Общие коэффициенты ущерба сохраняют целочисленное деление Java внутри `exp(strength / correctionFactor)`. Периоды сохраняют целочисленную семантику. Для площадей оставлено исходное `3.14`.
2. Отрицательные радиусы регрессии, перепутанный порядок зон и чрезмерные значения приводятся к конечным вложенным радиусам от 0 до 6370 км. Период не меньше одного дня.
3. При выходе зон за регион площадь каждого кольца делится на локальную и внешнюю части. Устранены отрицательные площади и неверные коэффициенты старых веток. Региональные итоги ограничены населением; общие — историческим глобальным населением. Региональное распределение итогов приближённое, пропорционально площади пересечения, и не является GIS-анализом реальных границ.
4. Для вируса логистическая производная считается устойчиво к переполнению. Раньше сумма зон смертности составляла 90% итогового значения и анимация могла не завершаться. Теперь последняя зона получает остаток, сумма зон равна итогу. Погибшие и пострадавшие — раздельные выходы старой модели; их не следует складывать как уникальных людей.
5. Расстояния до сооружений считаются по сфере (Haversine), а не по разности широты и долготы одной точки. Вычеты теперь действительно меняют итог — старые Java `Long` передавались по значению. Вместимость ограничена типом здания и применяется один раз к содержащей его зоне. Модель эффективности сооружений упрощена и не воспроизводит недостижимые ветви старой функции.
6. Химические таблицы сохранены. Исправлены поиск индекса температуры, получение коэффициента ветра вместо `indexOf`, нулевая база индекса скорости ветра и безопасные границы таблиц. Для семи температурных колонок задан ряд −30, −20, −10, 0, 10, 20, 30 °C; это явно выбранная интерпретация неполной старой индексации, требующая предметной проверки. При превышении верхнего порога массы Q используется последняя колонка, а не нулевой радиус.
7. Устранён безусловный вызов химической модели при расчёте других типов: они принимают запрос без химических параметров.
8. Вместо случайного приращения времени по кадрам — воспроизводимая интерполяция за 20 секунд с поддержкой паузы и задержки смертности. Она не претендует на физическое моделирование динамики.

Unit-тесты проверяют известные формулы радиусов, все 162 сочетания типа/силы/скорости/масштаба, справочники локаций, все бомбы/космические объекты, границы химических таблиц, детерминизм, суммы зон, географические расстояния и задержку смертности. Это инженерные проверки, не научная валидация.

## Не переносится автоматически

- Старые пробные отчёты SQL/Express: они не становятся отчётами новых анонимных посетителей.
- Старые учётные данные БД, Mapbox, адреса серверов и токены.
- Личные материалы авторов и внешние картинки.
- Имена авторов в метаданных PDF; страницы исходной инструкции сохранены. Скриншоты внутри документа отражают историческую версию (включая удалённые внешние иллюстрации и прежний переключатель локального сервера).

Для импорта реальной старой пользовательской истории потребуется отдельное сопоставление владельцев и проверка связности исходных записей. В исходной платформе полноценной модели владельцев не было.
