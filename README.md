# Emergency Analyzer

Единое приложение на Next.js App Router + TypeScript: интерфейс, расчёты и HTTP API в одном репозитории. Подготовлено для Vercel; постоянная история отчётов — в Neon PostgreSQL. Java, Gatsby и отдельный Express-сервер больше не нужны.

Интерфейс воспроизводит исходный Gatsby-проект: полноэкранная карта и центральное меню, нижняя панель, настройки через модальные списки, горизонтальные описания, таблица отчётов и панель симуляции. Разметка переписана на TypeScript и CSS Modules; исходный JavaScript и styled-components в приложение не включаются. Удалены авторство и внешние иллюстрации согласно согласованным изменениям.

## Запуск

Нужны Nix, devenv и direnv. Node.js 24, pnpm, PostgreSQL для интеграционных тестов и Chromium для браузерных проверок предоставляет `devenv.nix`. Окружение повторяет подход `wow-places`; команды автоматически создаются из `package.json` с префиксом `ea-`.

```sh
cd emergency-analyzer
direnv allow
pnpm install --frozen-lockfile
cp .env.example .env.local
ea-dev
```

Открыть http://localhost:3000. Для команд без direnv используйте `devenv shell -- ea-dev`. Чтобы direnv автоматически активировал окружение, его shell hook должен быть включён в настройках вашей оболочки.

Без секретов работают все шесть расчётных сценариев, локальная обзорная карта, воспроизведение, настройки, CSV и PDF-инструкция. Отчёты без БД сохраняются в `sessionStorage` текущей вкладки. Для детальной карты задайте `NEXT_PUBLIC_MAPBOX_TOKEN`. Для постоянных отчётов задайте `DATABASE_URL`, `SESSION_SECRET` и выполните `ea-db-migrate`.

## Команды

| Команда                    | Назначение                                     |
| -------------------------- | ---------------------------------------------- |
| `ea-dev`                   | Разработка                                     |
| `ea-build`, `ea-start`     | Production-сборка и запуск                     |
| `ea-check`                 | Форматирование, линтер, TypeScript, unit-тесты |
| `ea-format`, `ea-lint-fix` | Oxfmt и Oxlint с исправлениями                 |
| `ea-test`                  | Расчёты, валидация, геометрия, CSV, сессии     |
| `ea-test-e2e`              | Браузерные тесты; сначала выполнить `ea-build` |
| `ea-db-migrate`            | Идемпотентное создание схемы отчётов в Neon    |

ESLint, Prettier, Babel, Gatsby, Spring, Firebase и старые deployment-конфиги отсутствуют. Все версии зависимостей зафиксированы; `pnpm-lock.yaml` и `devenv.lock` входят в репозиторий.

## Структура

```text
src/app/              маршруты, layout, API-обработчики, глобальные стили
src/apps/shell/       навигация, настройки языка/темы, обзор
src/apps/simulator/   последовательные настройки, модальные списки, описания, карта, проигрыватель
src/apps/reports/     история и хранение в текущей вкладке
src/apps/reference/   просмотр исходных локальных PDF на RU/EN
src/components/       типизированные UI-компоненты, исходные SVG-иконки и обзорная карта
src/core/settings/    модель настроек и преобразование в запрос расчёта
src/core/i18n/        исходные переводы и сообщения без авторства
src/core/catalog/     исторические справочники, типизированный доступ
src/core/simulation/  чистые расчёты, схемы валидации, временная шкала
src/core/reports/     экспорт отчётов
src/core/map/         локальная геометрия стран
src/server/           Neon, подписанные сессии, HTTP-ошибки
src/utils/            геометрия и загрузка файлов
migrations/          SQL-схема отчётов
tests/               unit и desktop/mobile e2e
```

Ядро не зависит от React, Next.js и БД. В маршрутах остаётся HTTP-обвязка; расчёты выполняются на сервере. Для serverless не используются фоновые циклы, локальные файлы с отчётами или общее состояние процесса.

## Данные и статус

По согласованному решению справочники перенесены из локального архива как исторические: 190 стран, 597 регионов, шесть типов сценариев. Исторический характер данных указан в окне «О приложении»; API и CSV содержат версию `legacy-2020`. Числа не являются актуальными демографическими данными. Модель учебная, научная корректность исходных коэффициентов не подтверждена.

Mapbox сохранён для нового токена. Внешние изображения, личные ссылки, подписи и фотографии авторов не перенесены. Исходные `../frontend` и `../backend` используются только для чтения и не нужны для запуска нового приложения.

Подробности: [деплой и переменные окружения](docs/deployment.md), [перенос функций и изменения моделей](docs/migration.md), [источники данных](docs/data-sources.md).

## Лицензия и хранение

Код приложения — [MIT](LICENSE). Сторонние ресурсы сохраняют собственные лицензии: [уведомления и источники](THIRD_PARTY_NOTICES.md).

В Neon хранится не более 250 отчётов на всё приложение; при новой записи удаляются старейшие. Без БД сохраняются последние 250 отчётов текущей вкладки.

`ea-test-db` запускает временный локальный PostgreSQL и проверяет глобальный лимит истории, конкурентные записи и откат транзакций. Подключение к Neon не требуется; тестовая БД удаляется после запуска.

Пустые строки между блоками проверяет Oxlint через `stylistic/padding-line-between-statements`: после директив и импортов, между функциями и типами, после условий, перед `return` и между группой React-хуков и вычислениями. Связанные объявления и последовательные хуки остаются вместе. `ea-lint-fix` добавляет отступы автоматически, затем `ea-format` нормализует форматирование. ESLint как отдельный линтер не установлен и не запускается; используется только совместимый плагин Stylistic.
