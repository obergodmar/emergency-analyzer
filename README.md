# Emergency Analyzer

Университетский проект для моделирования чрезвычайных ситуаций и визуализации их последствий на карте. Приложение позволяет выбрать территорию и параметры катастрофы, воспроизвести сценарий и оценить предполагаемые масштабы поражения.

**Исходная разработка:** 2020–2021 годы. Первый коммит — 26 октября 2020 года.

**Сайт:** [emergency-analyzer.obergodmar.tech](https://emergency-analyzer.obergodmar.tech)

## Возможности

- Шесть сценариев: ядерный взрыв, эпидемия, наводнение, землетрясение, падение небесного тела и техногенная катастрофа.
- Выбор страны, региона и параметров события.
- Визуализация зон поражения и воспроизведение развития ситуации.
- Расчёт предполагаемого числа погибших и пострадавших.
- История симуляций и экспорт отчётов в CSV.
- Русский и английский интерфейс, светлая и тёмная темы.

Модель предназначена для учебных целей. Справочные данные относятся к периоду исходной разработки и не являются актуальной статистикой; результаты не следует использовать для реального планирования действий при чрезвычайных ситуациях.
